# OpenCalculate

just a calculator i made. open index.html in your browser and ur good

files:
- index.html
- style.css
- script.js

stuff it does:
- normal calc
- scientific mode (sin cos log etc)
- type stuff yourself like 15*24
- history (stays on your computer)
- light/dark theme
- keyboard works too

keyboard:
- numbers + operators
- enter or = for answer
- backspace deletes
- esc clears

nothing gets sent anywhere. history is local only
