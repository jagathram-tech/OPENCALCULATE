# OpenCalculate

This is a simple calculator website. It works in the browser. You don’t need to install anything.

## How to open

Just open the `index.html` file in Chrome or any browser.

## What is inside

- `index.html` — the main page
- `style.css` — how it looks (black and white)
- `script.js` — all the calculator code

## What it can do

- Normal calculator (add, subtract, multiply, divide)
- Scientific mode (sin, cos, log, sqrt, etc.)
- You can type the sum yourself, like `15 * 24` or `2^10`
- History of your calculations (saved only on your computer)
- Light mode and dark mode
- Works with keyboard also

## Keyboard

- Numbers: `0` to `9`
- Operators: `+` `-` `*` `/`
- Enter or `=` to get answer
- Backspace to erase
- Escape to clear

## Privacy

Nothing goes to the internet. Your history stays only on your device.
